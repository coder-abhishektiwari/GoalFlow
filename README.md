# GoalFlow

[![Platform](https://img.shields.io/badge/platform-iOS%20%7C%20Android-lightgrey?style=flat-square)](https://expo.dev)
[![Made with](https://img.shields.io/badge/made%20with-React%20Native-blue?style=flat-square)](https://reactnative.dev)
[![License](https://img.shields.io/badge/license-MIT-green?style=flat-square)](LICENSE)

**Bade goals ko chote steps mein todo. Ek ek step complete karo. Aage badho.**

Mostly banaya isliye kyunki bade goals dekhke overwhelming lagta hai aur pata nahi hota shuru kahan se karna hai. GoalFlow hamesha screen pe dikhaata hai ki *abhi sirf yeh ek kaam karo* — baaki sab baad mein.

</div>

---

## Features

- 🎯 &nbsp; Goal banao — naam, category, deadline, aur micro-steps
- 🏠 &nbsp; Home pe hamesha dikhta hai aaj ka **current step**
- ✅ &nbsp; Step complete karo — ek tap, confetti, aur next step ready
- 📊 &nbsp; Insights mein dekho kitne goals done hue, kitne baaki hain
- 🌙 &nbsp; Dark mode supported, 100% offline, data sirf device pe
