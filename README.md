# GoalFlow

[![Platform](https://img.shields.io/badge/platform-iOS%20%7C%20Android-lightgrey?style=flat-square)](https://expo.dev)
[![Made with](https://img.shields.io/badge/made%20with-React%20Native-blue?style=flat-square)](https://reactnative.dev)
[![License](https://img.shields.io/badge/license-MIT-green?style=flat-square)](LICENSE)

**Break big goals into small steps. Complete them one by one. Keep moving forward.**

Built because big goals feel overwhelming and you never know where to start. GoalFlow always shows you on screen — *just do this one thing right now* — everything else can wait.

</div>

---

## Features

- 🎯 &nbsp; Create a goal — name, category, deadline, and micro-steps
- 🏠 &nbsp; Home screen always shows your **current step** for today
- ✅ &nbsp; Complete a step — one tap, confetti, and your next step is ready
- 📊 &nbsp; Insights to see how many goals are done and how many are left
- 🌙 &nbsp; Dark mode supported, 100% offline, data stays only on your device

## Setup

```bash
git clone https://github.com/coder-abhishektiwari/GoalFlow.git
cd GoalFlow
npm install
npx react-native run-android
```

Install Expo Go on your phone, scan the QR code — you're good to go.
